# LECTURE-02 — STEP 4 Proof of Work 체험도구 v3

강의 「블록체인은 왜 '블록체인'일까?」를 위한 정적 웹 체험도구입니다.

## 포함된 단계

- STEP 1 — SHA-256 Hash
- STEP 2 — Block
- STEP 3 — Chain
- STEP 4 — Proof of Work

네 단계가 하나의 앱 안에서 이어지며 URL fragment로 직접 이동할 수 있습니다.

- `#hash`
- `#block`
- `#chain`
- `#pow`

## STEP 4 구성

STEP 4는 두 부분으로 나뉩니다.

### STEP 4-A — 사람이 직접 Mining

Chain의 Block #3 뒤에 붙일 새 `Block #4`의 **동일한 거래 데이터와 Previous Hash**를 사용합니다. 실습 데이터를 별도로 조정하지 않았습니다.

학생은 `0~10,000` 사이의 원하는 Nonce를 직접 입력합니다. 입력하는 순간 별도 버튼 없이 Hash가 즉시 다시 계산됩니다. Nonce 입력칸은 숫자 스피너(▲▼)를 사용하지 않아, 버튼을 누르고 있는 방식으로 자동 증가시킬 수 없습니다. 반드시 숫자를 직접 입력합니다.

수동 난이도는 두 단계입니다.

- 먼저 해보기: Hash가 `0`으로 시작
- 난이도 올리기: Hash가 `00`으로 시작

현재 데이터 기준 첫 성공 Nonce는 다음과 같습니다.

- `0` 조건: Nonce `13` → `0b37636b...`
- `00` 조건: Nonce `474` → `0091fb52...`

`0` 조건을 너무 빨리 찾았다면 수업 중 바로 `00` 조건으로 올려 같은 방식으로 계속 탐색할 수 있습니다.

### STEP 4-B — 컴퓨터가 자동 Mining

학생이 직접 하던 일을 컴퓨터가 자동으로 반복합니다. Block의 거래와 Previous Hash는 그대로 두고 `Nonce`만 `0, 1, 2, 3 ...` 증가시키며 SHA-256을 반복 계산합니다.

자동 난이도는 기존과 동일합니다.

- 쉬움: `00`으로 시작
- 기본: `000`으로 시작
- 어려움: `0000`으로 시작

화면에는 다음 값이 실시간으로 표시됩니다.

- 현재 Nonce
- 현재 Block Hash
- 시도 횟수
- 소요 시간

16진수 한 자리가 `0`일 확률은 1/16이므로, 앞의 0이 하나 늘어날 때 필요한 시도 횟수는 평균적으로 약 16배 증가합니다. 실제 시도 횟수는 Hash 결과에 따라 달라집니다.

현재 고정된 실습 데이터에서는 다음 Nonce에서 처음 조건을 만족합니다.

- 쉬움: Nonce `474` / 475회 시도
- 기본: Nonce `9,151` / 9,152회 시도
- 어려움: Nonce `49,867` / 49,868회 시도

## 교육적 흐름

1. **Hash** — 입력이 조금만 바뀌어도 Hash가 크게 달라짐
2. **Block** — 여러 기록을 한 Block으로 묶고 Block 전체에 Hash를 계산
3. **Chain** — 앞 Block의 Hash를 다음 Block이 Previous Hash로 기억
4. **수동 PoW** — 학생이 직접 Nonce를 넣으며 조건을 만족하는 Hash 탐색
5. **자동 PoW** — 방금 한 반복 작업을 컴퓨터가 빠르게 수행

STEP 4의 목적은 실제 Bitcoin Mining 전체를 재현하는 것이 아니라, **"Nonce를 바꾼다 → Hash를 계산한다 → 조건을 확인한다"**는 반복과 **"조건이 어려워질수록 더 많은 계산이 필요하다"**는 점을 직관적으로 체험하게 하는 것입니다.

## 개인정보 및 네트워크

입력값은 외부 서버로 전송되지 않습니다. SHA-256과 Mining 계산은 모두 브라우저 안에서 수행됩니다. 외부 API, 데이터베이스, 회원가입 기능을 사용하지 않습니다.
